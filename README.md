Sistema de Gestão de Voos Corporativos

Sistema web desenvolvido para gerenciar e controlar os voos corporativos.

Objetivo

Centralizar as informações relacionadas às viagens realizadas com a aeronave da empresa, permitindo o controle de:
	•	Voos;
	•	Passageiros;
	•	Finalidade das viagens;
	•	Abastecimentos;
	•	Custos;
	•	Histórico de utilização.

O sistema busca facilitar a organização, rastreabilidade e gestão dos voos corporativos
